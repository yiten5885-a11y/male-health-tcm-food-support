# 男性问题中医调节方案

![封面](cover.png)

一个面向 Codex 的完整开源 Skill：将已获授权的两份男性健康来源资料转换为用户能读懂的食疗辅助方案，并强制加入单方试用、每日频次、3 天回访、7 天复核及低风险放松建议。

## 这个仓库公开了什么

- 可直接运行的 Skill 指令、查询/编排代码、552 条结构化来源记录与原页核验图。
- 7 张原创用户引导图、含中文名与服务介绍的项目封面。
- 清晰的食疗试用与反馈协议，以及来源追溯模式。

## 这个仓库不公开什么

- 原始 PDF 文件；Skill 已包含运行所需的结构化记录与核验页图，无需下载 PDF。
- 任何超出已公开资料范围的补写、疗效承诺或个体医疗处方。

本仓库由资料权利方明确授权公开发布；来源转录核对不等于临床有效性或安全性评价。

## 给用户的体验

用户直接说：

```text
最近勃起不太稳定，胃口正常，没有长期用药。请给我一份食疗辅助方案。
```

有获授权资料时，Skill 只选一道作为初试：随正餐每天 1 次，先试 3 天。第 3 天用户反馈消化耐受、症状变化和不适；耐受良好才保持每天 1 次至第 7 天，再决定停用、维持或换一道。它不会因为来源资料写有“每日多次”就让每个人自行加量，也不会叠加多道方案。

## 安装与资料接入

1. 将 `skill/` 安装为 Codex Skill。
2. 用户通过自然语言提问，不需要接触 PDF、记录 ID 或命令。
3. 只有用户明确问原书页码、记录 ID、审核状态或原文证据时，才进入来源追溯模式。

仓库已包含 `skill/assets/records.jsonl` 与 `skill/assets/evidence/`。请勿把其中的来源转录或页面核验图误称为临床证据。
