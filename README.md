# 男性问题中医调节方案

![封面](cover.png)

一个面向 Codex 的开源 Skill 框架：将**已获授权**的结构化食疗资料转换为用户能读懂的食疗辅助方案，并强制加入单方试用、每日频次、3 天回访、7 天复核及低风险放松建议。

## 这个仓库公开了什么

- 原创 Skill 指令、Python 查询/编排代码和用户版引导图。
- 清晰的食疗试用与反馈协议。
- 一个不含受控来源资料的资料接入规范。

## 这个仓库不公开什么

- 任何未经明确再发布授权的 PDF、扫描页、插图、完整转录、记录数据或来源证据图。
- 不能在资料缺失时自动补写的“药膳方”或原书文字。

这一区分是故意的：公开代码与视觉资产不等于拥有来源内容的公开发行权。

## 给用户的体验

用户直接说：

```text
最近勃起不太稳定，胃口正常，没有长期用药。请给我一份食疗辅助方案。
```

有获授权资料时，Skill 只选一道作为初试：随正餐每天 1 次，先试 3 天。第 3 天用户反馈消化耐受、症状变化和不适；耐受良好才保持每天 1 次至第 7 天，再决定停用、维持或换一道。它不会因为来源资料写有“每日多次”就让每个人自行加量，也不会叠加多道方案。

## 安装与资料接入

1. 将 `skill/` 安装为 Codex Skill。
2. 仅将已拥有再发布与使用许可的结构化数据放入 `skill/assets/records.jsonl`。
3. 按 [data/README.md](data/README.md) 校验字段、授权范围和来源审计信息。
4. 用户通过自然语言提问，不需要接触 PDF、记录 ID 或命令。

当前仓库没有附带 `records.jsonl`，因此在未接入获授权资料时只能输出资料缺失提示。这是版权边界，不是安装故障。
