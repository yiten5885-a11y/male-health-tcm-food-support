# 获授权资料接入

`skill/assets/records.jsonl` 是运行时资料入口，但本公开仓库有意不附带该文件。

接入者必须确认并保留以下证据：

1. 资料内容可以用于本地检索和向终端用户展示。
2. 如计划公开仓库、发布数据集或提供下载，权利人已明确同意再发布；仅拥有纸书或 PDF 副本不等于拥有公开传播权。
3. 每条记录含来源标识、来源页码或其他可审计定位信息、字段不确定性和适用边界。
4. 未经验证的疗效、安全性、剂量、频次、私密部位操作或专业手法不得转为个体执行指令。

资料接入后，先用本地测试和人工抽样核对，再允许用户查询。不要把受版权保护的整页图片或大段转录写入公开 issues、README、示例或测试快照。
