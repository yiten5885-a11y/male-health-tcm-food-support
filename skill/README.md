# 男性问题中医调节方案

![男性问题中医调节方案封面](assets/cover/male-health-tcm-food-support-cover.png)

把两本来源资料整理为对普通用户可读的食疗辅助方案与居家低风险放松建议。它的目标不是让用户翻 PDF、看数据库字段或照着原书自行加量，而是每次输出一份可以执行、可以回访、可以根据消化耐受调整的初版方案。

## 用户会得到什么

- 1～2 道与其描述相近的食疗做法：原料、做法、原书用法、原书所述用途与已知宜忌。
- 每道方案的固定初始节奏：一次只选一道，随正餐每天 1 次，先试 3 天。
- 第 3 天回访清单：消化耐受、皮疹或其他不适、原问题变化；耐受良好才保持同频次至第 7 天，再次反馈后决定停用、维持或换一道。
- 按问题路由的非私密、非脊柱扳动、舒适力度的放松步骤和相应示意图。

## 使用方式

安装本 Skill 后，直接对助手说出实际困扰即可，例如：

```text
最近勃起不太稳定，胃口正常，没有长期用药。请给我一份食疗辅助方案。
```

首次不必提供所有信息。为了让第二轮更贴合个人耐受，建议补充：症状持续多久、是否突然出现、晨勃是否变化、慢性病或长期用药、食物过敏、是否容易胀气/反酸/腹泻/便秘。

### 第 3 天怎么反馈

把下面这段直接复制回对话并填空：

```text
我试的是【方案名】；已经吃了【】天，每天【】次。
消化情况：【正常／胀气／反酸／恶心／腹痛／腹泻／便秘／其他】。
原来的问题变化：【无变化／略有变化／加重，具体是】。
其他不适、过敏或皮疹：【无／有，具体是】。
慢性病和长期用药：【无／有，具体是】。
```

助手只能据此在“停用、维持每天 1 次、换一道”之间作保守调整；不会把食疗包装成诊断、疗程或治疗替代。

## 方案规则

“原书用法”是来源资料的转录；“本次试用节奏”是为减少同时变量和消化负担而设置的助手规则，两者不能混为一谈。即使原书出现“每日多次”，首次也不自行加量，也不把两道食疗叠加使用。含酒、药材或陌生食材的方案，以及存在食物过敏、慢性病、长期用药或特殊饮食限制时，不按默认节奏自行尝试。

出现过敏表现、明显胃肠不适或原有症状加重时，停止该方案。突发或剧烈疼痛、睾丸疼痛或肿胀、出血、外伤、麻木、高热、胸痛、呼吸困难或晕厥时，不生成食疗或按摩步骤。
